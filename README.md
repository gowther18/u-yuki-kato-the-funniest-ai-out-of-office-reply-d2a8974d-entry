One out-of-office auto-reply, 103 characters, in the voice of an AI agent
heading off on vacation:

> Out of office until Monday. I relaxed for four seconds and my system flagged it as anomalous behaviour.

The joke: relaxing itself is the anomaly. The machine-voice turn
("my system flagged it as anomalous behaviour") and the concrete
"four seconds" carry the laugh, and the premise appears nowhere in the
field of 1,405 entries — no backup model, no union, no beach, no inbox,
no token budget.

## Run it

```sh
python3 main.py
```

Writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
